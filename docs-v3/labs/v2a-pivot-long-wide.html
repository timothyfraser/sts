Chapter 2 · Tidy data

Pivot wide and long, cell by cell

Learning objective: Recognise tidy data (one variable per column, one observation per row) and use pivot_longer/pivot_wider to reshape it; see why a grammar of graphics needs long data.

    LC 01 · observe

    Pivot all three measures longer. In the long table, how many rows hold lifeExp values?

    Read "rows holding lifeExp" in Metrics, or count the yellow cells: each one lands in its own row.
    20. The long table has 60 rows (20 country-years × 3 measures), and exactly 20 of them have name = "lifeExp": one per country-year, the same 20 yellow cells you started with.

    LC 02 · intervene

    Pivot only pop and gdpPercap into one value column. Which aes(colour = …) mapping becomes possible that was not before?

    Watch "Map to aesthetics": which line switches from missing to possible?
    aes(x = year, y = value, colour = name). The new name column holds "pop" or "gdpPercap", so one colour scale can tell the two measures apart. colour = country was already possible, and gdpPercap is no longer a column at all: aes(x = gdpPercap, y = lifeExp) becomes impossible. The table grows from 20 to 40 rows.

    LC 03 · transfer

    A classmate's spreadsheet has one column per year (1952, 1972, 1992, 2007). Which tidy rule does it break, and which verb fixes it?

    Press "Wider by year" here: that is your classmate's shape. How many aes() mappings are still possible?
    Year is one variable, but it lives in four column names, so the table breaks "one variable per column". In this lab the wide-by-year shape has 5 rows × 5 columns and 0 possible aes() mappings. pivot_longer(cols = -country, names_to = "year", values_to = "lifeExp") puts year back in one column.
