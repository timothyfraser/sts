LC 01 · observe
Switch to "Send raw rows" for JFK in January. How large is the JSON payload?

      

      
Read "payload bytes" in the sidebar, or the size above the JSON preview. The filter still runs on the server; only the summarize step moves to the browser.

      
602,825 bytes: every one of the 9,161 January JFK flights travels as a JSON row. Computing on the server sends 10 carrier rows in 327 bytes, about 1,800 times smaller.

    
LC 02 · intervene
Turn caching on, then press "Send the same request again". Which steps are skipped the second time?

      

      
Watch the dashed hop in the diagram and "steps run" in the sidebar. memoise lives inside plumber.R, not in the browser.

      
The second call still goes React to Plumber and back as JSON, but get_data() answers from the cache: steps run falls from 4 to 3 and the modeled time from 131 ms to 25 ms.

    
LC 03 · transfer
Two charts on a dashboard need the same statistic. What is the trade-off of one shared endpoint vs one endpoint per chart?

      

      
Toggle the endpoint design: the payload bytes do not change, but the URL and the annotation do.

      
Both designs send the same 327 bytes here. A shared /stat endpoint takes a stat parameter, runs one R function and fills one cache that both charts hit; /carrier-mean-arr-delay is clearer on its own but a second chart means a second endpoint, a second function and a second cache.
