# Vendored impeccable skill

`.claude/skills/impeccable/` is a vendored copy of the impeccable skill from
https://github.com/pbakaus/impeccable at tag `skill-v4.1.0` (commit `2c33196c51ac52e47691384e61d89f1218d8d21d`),
path `.claude/skills/impeccable`. It is copied rather than linked so that every checkout
and git worktree has the skill without a submodule step. The detector CLI is `npx impeccable@4.1.0`.
To update: check out a newer tag of the upstream repo and replace the directory.
